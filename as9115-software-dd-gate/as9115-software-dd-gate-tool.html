AS9100D Cl. 8.3
AS9115

Project & Software Context

Identify the product, software classification, and applicable standard overlay. AS9115 requirements supplement AS9100D Cl. 8.3 — both gate sets apply.

Gate 1 — Planning (AS9100D Cl. 8.3.2)

Verify that design and development planning evidence is established before detailed design work begins. Check each item present and evidenced.

Gate 2 — Inputs (AS9100D Cl. 8.3.3)

Verify that design inputs are documented, reviewed, and complete before committing to detailed design outputs.

Gate 3 — Outputs & Reviews (AS9100D Cl. 8.3.4 / 8.3.5)

Verify that design outputs meet input requirements and that formal design reviews have been conducted and recorded.

Gate 4 — Verification & Validation (AS9100D Cl. 8.3.6 / 8.3.7)

Verify that V&V activities are planned and completed before release to production or customer delivery.

Gate 5 — Software-Specific Requirements (AS9115 Overlay)

AS9115 extends AS9100D for software-intensive aerospace products. These items supplement the base D&D gates. All applicable items must be satisfied before software release.
