FIRST CAR WALKTHROUGH
================================================================================

1. App opens, click "+ NEW"
2. Fill in:
   - Title: "My First CAR"
   - Owner: "Your Name"
   - Email: "your@email.com"
3. Click Create
4. D0 panel opens in center
5. Type in DETAILS box (your team description)
6. Watch M-AI Kernel scores on right update in real-time
7. Add owner: name + email, click "Add Owner"
8. Click "In Progress" button
9. Click "Complete" button
10. Fill in Verification (Approver name + email)
11. Click "Verify" button
12. D0 turns GREEN in sidebar ✓
13. D1 unlocks, click D1 to continue
14. Repeat for D2-D8

When all 9 are complete and verified:
   → Export as JSON to backup
   → Print report for your records
   → View audit log to see all changes

================================================================================
TROUBLESHOOTING
================================================================================

❌ "npm: command not found"
   → Install Node.js from https://nodejs.org
   → Restart terminal after installing

❌ "Port 3001 already in use"
   → Change PORT in .env file
   → Or close other apps using that port

❌ "Module not found"
   → Run: npm install
   → Then: npm run dev

❌ "App won't start"
   → Check console for errors (DevTools should be open)
   → Try: npm install again
   → Delete node_modules, run npm install fresh

❌ "Database error"
   → Delete data/ folder
   → Run: npm run dev (recreates database)
