## Readiness Key

| Status | Meaning |
|--------|---------|
| ✅ Ready to Sell | Production build complete — distributable today |
| 🔜 Near Release | Feature complete; final QA or packaging step remaining |
| 🔧 Under Construction | Core engine exists but significant features not yet built |
| ❓ Not assessed | Built and present; readiness not yet reviewed this cycle |

---

## Conventions

- Every application has its own subfolder here — one folder per app.
- Applications that also exist as standalone repositories under [Airgate-Pty-Ltd](https://github.com/Airgate-Pty-Ltd) link to those repos via the folder link above.
- Static tools (single-file HTML) are distributed as downloads; server-backed apps target Railway or equivalent PaaS.
- Android apps use Capacitor wrapping a vanilla JS bundle; iOS support is not planned at this stage.
- Apps marked ❓ are candidates for the next readiness review cycle — they are built and present, not incomplete.
- Readiness status is updated at each significant milestone commit.
