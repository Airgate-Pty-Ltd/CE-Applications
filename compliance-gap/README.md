# ComplianceGap

Compliance gap analysis application powered by VERA AI.

## Quick Start

```bash
# Install dependencies
cd frontend && npm install
cd ../backend && npm install

# Run development
cd frontend && npm run dev
cd ../backend && npm run dev
```

## Deployment

Deployed to Railway. See Railway dashboard for service URL.

Environment variables:
- `VERA_SERVICE_URL` - VERA-Core API endpoint
- `PORT` - Server port (default: 3000)
