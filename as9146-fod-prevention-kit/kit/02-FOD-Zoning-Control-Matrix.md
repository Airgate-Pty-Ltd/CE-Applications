# FOD Zoning Control Matrix — QP-FOD-001 Attachment A

| Control | Normal | FOD-Aware | FOD-Critical |
|---|---|---|---|
| Tool accountability | Basic | Shadow board | Shadow board + tethering + pre-close reconcile |
| Personal items | Allowed | Restricted | Prohibited (no loose items, badges tethered) |
| Consumable control | Standard | Point-of-use bins | Logged issue/return of offcuts, lock-wire, fasteners |
| Housekeeping | Daily | Clean-as-you-go | Continuous + end-of-shift FOD walk documented |
| Entry control | None | Signage | Briefed entry, FOD check on entry/exit |
| Inspection before closure | N/A | Visual | Documented FOD check + independent verify |

*Assign each area a zone on the site map. Where a contract/customer spec invokes stricter control, that governs.*
