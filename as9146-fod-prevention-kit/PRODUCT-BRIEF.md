# Product Brief — as9146-fod-prevention-kit

## Product Name
FOD Prevention Program Kit (AS9146-aligned)

## Product Category
Annex Quality hard-copy product — implementation kit (print-ready QMS document set + self-assessment)

## Buyer
Quality/operations managers at aerospace & defense manufacturers, assemblers, and MROs — especially SMEs newly flowed-down AS9146 by Boeing/Airbus/primes.

## Pain
Primes increasingly require a documented FOD program (AS9146). SMEs lack one and face a finding or lost qualification. Writing it from scratch takes weeks of scarce quality-engineer time.

## Decision Supported
"Do we have a defensible, audit-ready FOD program, and where are our gaps?"

## Data Required
Site zoning inputs and honest self-assessment ratings; the kit supplies everything else as editable templates.

## Evidence Produced
A complete controlled FOD program: procedure, zoning matrix, 3-level inspection checklist, event log + deterministic RCCA trigger rules, training pack, and a scored self-assessment with a PROGRAM-READY / CONDITIONAL / NOT-READY verdict.

## Recommendation Logic
Self-assessment uses fixed core-element gates (procedure, tool accountability, inspection, RCCA) — any core zero forces NOT READY; ≥85% with no core zeros ⇒ READY.

## Business Outcome
Weeks of authoring avoided; audit finding avoided; prime qualification protected.

## Why This Is Different
Not a generic template dump — it ships with deterministic RCCA trigger rules and a scored readiness verdict, so the buyer gets a decision, not just documents.

## Pricing Hypothesis
$399 single-site kit; $1,200 multi-site/enterprise license. Path to $250k: ~520 kits/yr @ $399 ≈ $207k + ~40 enterprise @ $1,200 ≈ $48k. Cross-sell from Annex Quality aerospace courses lifts volume.

## First-Dollar Path
Offer to Brian's aerospace supplier network and Annex Quality list; deliver as a zipped Markdown/Word kit via emailed link.

## Reuse / IP Captured
Reusable FOD program IP for Annex Quality catalogue; the deterministic self-assessment structure seeds a future Conform-Edge FOD readiness tool (parallels the Nadcap engine built the same run).
