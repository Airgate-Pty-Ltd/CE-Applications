# Inspection Templates

FAI template snapshots for the "Load Template" Part Setup mode. Each template is a locked FAI record stripped to its characteristic list and balloon layout.

## Format

```json
{
  "template_id": "UUID",
  "part_number": "PN-XXXXX",
  "part_revision": "A",
  "created_from": "inspection-record UUID",
  "locked_at": "ISO8601",
  "characteristics": [
    {
      "id": 1,
      "description": "...",
      "nominal": 0.0,
      "upper_tolerance": 0.0,
      "lower_tolerance": 0.0,
      "unit": "mm",
      "type": "dimensional"
    }
  ]
}
```

## Use

When a user selects "Load Template" in Part Setup, the app loads the template's characteristic list and balloon layout. The user enters a new serial number and begins the inspection. No prior measurement values are inherited — only nominal, tolerance, and description fields.
