# Risks, Assumptions, Legal/Regulatory Boundaries

## Risks
1. **Template competition:** free MR agenda templates abound. Mitigation: evidence
   calibration + multi-standard deltas + generated action register are the moat.
2. **Browser-only storage:** users can lose data by clearing cache. Mitigated by export
   prompts; server storage is a v1.2 feature.
3. **Standard revision risk:** ISO 9001:2026 (expected ~Sept 2026) will change inputs.
   This is also an upsell event — pack architecture makes updates data-only.
4. **Claims-vs-capability gate** (per 07-07 evolution finding): all copy in this build
   states exactly what the tool does. No live-data or AI claims in MVP copy.

## Key assumptions
1. [ASSUMPTION] >1M active ISO 9001 certificates; MR pain frequency 1–4×/yr.
2. [ASSUMPTION] $79/mo clears a QM's approval threshold without procurement.
3. [ASSUMPTION] Clause decompositions from Brian's skills are current as of 2026-07.
4. [ASSUMPTION] Buyers accept browser-local data for MVP (no server storage).

## Legal/regulatory boundaries
- MRA is a documentation aid. It does **not** certify compliance, does not replace
  top management judgment, and outputs are advisory. Disclaimer embedded in app footer
  and export.
- No standard text is reproduced verbatim — clause-by-intent paraphrase only
  (copyright-safe per tpecs-traceability practice).
- No customer data leaves the browser in MVP — state this plainly; it is a selling
  point for ITAR-adjacent aerospace buyers.
