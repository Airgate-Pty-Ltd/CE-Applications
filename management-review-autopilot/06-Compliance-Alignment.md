# Compliance Alignment — Clause/Evidence Map

MRA converts requirements into usable records, not mentions. Core mappings:

## ISO 9001:2015 §9.3 (foundation)
| Requirement | MRA feature | Evidence produced |
|---|---|---|
| 9.3.1 planned intervals | Review metadata (date, cycle, attendees) | Minutes header + Record of Review |
| 9.3.2 a) status of prior actions | Dedicated input card + action register carryover | Action register with status |
| 9.3.2 b) changes in external/internal issues | Input card w/ auditor guidance | Minutes §Inputs |
| 9.3.2 c) 1–7 performance info (satisfaction, objectives, process performance & conformity, NC/CA, monitoring results, audit results, supplier performance) | 7 discrete cards — cannot be silently skipped | Coverage report + minutes |
| 9.3.2 d) resource adequacy | Input card | Minutes + resource-need outputs |
| 9.3.2 e) risk/opportunity action effectiveness | Input card | Minutes |
| 9.3.2 f) opportunities for improvement | Input card | Feeds output register |
| 9.3.3 outputs (improvement / QMS change / resource needs) | Output-action register, typed by 9.3.3 category | Actionable register w/ owner+due |
| 7.5 documented information | Markdown/print export, revision block | Retained record |

## AS9100D deltas (adds to above)
- On-time delivery performance — dedicated card (§9.3.2 c emphasis)
- Customer satisfaction incl. product conformity & delivery — strengthened card guidance

## AS9110C deltas
- Safety objectives / human factors program results card
- Airworthiness/regulatory compliance status card (FAA/EASA linkage guidance)

## ISO 13485:2016 §5.6 deltas
- Reporting to regulatory authorities card (§5.6.2 f)
- Complaint handling card (§5.6.2 e), advisory notices guidance
- New/revised regulatory requirements card (§5.6.2 i)
- Output: maintained effectiveness of QMS **and processes** wording

## Scan-mandate themes coverage
Process approach (board mirrors process results), risk-based thinking (risk-action
effectiveness input), documented information (export/retention), competence (resource
adequacy card), supplier control (supplier performance card), NC/CA (dedicated card),
internal audit (audit results card), management review (the product), continual
improvement (output register).
