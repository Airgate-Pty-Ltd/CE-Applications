# Part-IS Gap Assessment Checklist
**[The Organization]** — Information Security Management System (ISMS) readiness
Applicable regulation: (EU) 2022/1645 (Part-21 / initial airworthiness organisations)
or (EU) 2023/203 (Part-145 / CAMO / continuing airworthiness organisations).
Reference requirements by clause number and intent only. Verify current AMC/GM
issue with EASA before use. [PLACEHOLDER: confirm AMC/GM revision in force]

**Rating:** C = Compliant (evidence exists and operates) · P = Partial
(documented but not evidenced/operating) · M = Missing.
A "C" rating without a cited record or clause is downgraded to "P".

| # | Requirement area (intent) | What the authority expects to see | Rating | Evidence cited |
|---|---------------------------|-----------------------------------|--------|----------------|
| 1 | ISMS scope & governance — the organisation defines which activities, assets, and interfaces are subject to information security management, approved at Accountable Manager level | Scoped ISMS statement integrated in the exposition/manual; AM signature | ☐ C ☐ P ☐ M | |
| 2 | Information security risk assessment — aviation-safety-driven, not IT-driven; identifies elements whose compromise could affect safety | Risk assessment register linking information assets to safety effects | ☐ C ☐ P ☐ M | |
| 3 | Risk treatment — proportionate controls selected and justified; residual risk formally accepted | Treatment plan; risk acceptance records | ☐ C ☐ P ☐ M | |
| 4 | Incident detection & response — capability to detect, respond to, and recover from information security events affecting scope | Detection means; response procedure; exercise/drill records | ☐ C ☐ P ☐ M | |
| 5 | External reporting — events with potential aviation-safety impact reported to the competent authority within required timescales | Reporting procedure naming authority, channel, and clock; sample or dry-run record | ☐ C ☐ P ☐ M | |
| 6 | Outsourcing & interfaces — contracted activities and interfaced organisations covered; security requirements flowed down | Contract clauses; interface register; supplier assessments | ☐ C ☐ P ☐ M | |
| 7 | Personnel competence & awareness — staff whose duties affect the ISMS are competent and aware | Training syllabus; completion records; role mapping | ☐ C ☐ P ☐ M | |
| 8 | Continuous improvement & internal audit — ISMS is audited and improved within the existing compliance monitoring programme | Audit programme entry; findings; management review inputs | ☐ C ☐ P ☐ M | |
| 9 | Integration — ISMS operates inside the existing (Q)MS/SMS, not as a parallel system | Cross-references in exposition/manual; single management review | ☐ C ☐ P ☐ M | |
| 10 | Documentation & record control — ISMS documents and records controlled per the organisation's documented information process | Controlled document list; retention rules | ☐ C ☐ P ☐ M | |
