### Keywords to Exclude (Non-requirements)

```
Patterns that are NOT requirements:

- "You should read..."
- "For example..."
- "This section describes..."
- "Consider..."
- "It is recommended..."
- "The following is an example..."

These are instructional text, not requirements.
```

## HOW TO USE THIS GUIDE

### Quick Start (5 minutes per standard)

1. **Copy a pattern** from above
2. **Paste into training dashboard**
3. **Click "Train Parser"**
4. **Repeat 5-10 patterns**

### Result

- Parser learns standard-specific keywords
- Extraction accuracy jumps 10-20%
- Recognize common requirement phrasings
- Reduce false positives

### Timeline

```
ISO 9001:         5 patterns × 5 min = 25 min
FAA Part 21:      4 patterns × 5 min = 20 min
EASA CS-23:       3 patterns × 5 min = 15 min
ISO 13485:        3 patterns × 5 min = 15 min
AS9100D:          4 patterns × 5 min = 20 min

Total: ~95 minutes → 90%+ accuracy
```

## VERIFICATION: After Training

### Test Extraction

1. Take sample standard (3-5 pages)
2. Extract with trained parser
3. Validate results
4. Check metrics:
   - Requirements extracted: Should be 80%+ of actual
   - Accuracy: Should be 85%+
   - Confidence: Should be 80%+ average
   - False positives: Should be <10%

### If Not Meeting Targets

- Train on 5 more patterns (focus on your misses)
- Re-extract
- Metrics should improve 5-10%
