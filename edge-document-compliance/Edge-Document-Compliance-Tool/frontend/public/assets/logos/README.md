# Logo Assets

Place your logo files here.

## Recommended Files

- `logo.png` - Main logo (32x32px or larger, transparent background)
- `logo.svg` - Vector logo (scalable)
- `logo-dark.png` - Dark mode variant (optional)

## Usage in HTML

Update `index.html` logo section to use:

```html
<img class="logo-img" src="/assets/logos/logo.png" alt="EDCAT Administrator">
```

Or for SVG:
```html
<img class="logo-img" src="/assets/logos/logo.svg" alt="EDCAT Administrator">
```

## Current Logo

The current logo is an inline SVG in the header. Replace the `<svg>` element with an `<img>` tag pointing to your logo file.
