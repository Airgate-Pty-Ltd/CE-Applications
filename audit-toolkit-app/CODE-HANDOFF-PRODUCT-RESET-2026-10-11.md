## 11. Known limitations of this prototype (carry forward; none hidden)
Synthetic data throughout; hierarchy is a catalogued sample (27 leaves, 22 unclassified); 5 AI-drafted obligations; coverage and duration rules are unverified planning rules; imported results are a synthetic export (no real import format defined); competency items are not expert-reviewed and the NCR scenario is a single fixed case; SCAR builder uses simple forms (no attachments, no real import formats beyond a key/value structure); storage is unencrypted browser `localStorage`; no authentication, roles or multi-user separation (planner/program author-approver separation is policy-flagged only); library update is simulated by a review aid; no real Pocket Auditor integration; no device/WebView testing; accessibility not audited; export is HTML/CSV/print, not a designed PDF; all earlier limitations in `ACCEPTANCE-SWEEP-REPORT.md` §4 still apply to the reference component.
