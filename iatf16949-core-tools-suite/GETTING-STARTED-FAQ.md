# Getting Started & FAQ — IATF 16949 Core Tools Suite
**Created:** 2026-07-07 (evolution pass — customer-success layer)

## Getting Started (5 steps)
1. Open the tool in any modern browser (Chrome, Edge, Firefox, Safari). No install, no login.
2. Enter your company name and assessment date on the first screen.
3. Work through the 6 tabs — APQP, PPAP, FMEA, MSA, SPC, IATF Integration (45 questions, ~30 minutes). Your answers save automatically on this device; you can close and resume anytime.
4. Review your maturity radar and the auto-generated gap list. Anything scored 1–2 is a likely audit finding; 3 is survivable but fragile; 4–5 is defensible.
5. Print the report (Ctrl+P → Save as PDF) or export CSV to trend quarter over quarter.

## FAQ

**Who should answer the questions?** Ideally the quality manager with the process owners in the room. Honest answers matter more than good scores — the tool is a mirror, not a certificate.

**Is my data uploaded anywhere?** No. Everything runs and stays in your browser (localStorage on your device). Nothing reaches a server.

**Is this an official IATF or AIAG product?** No. It is an independent assessment tool built by an IATF 16949 lead auditor. It references requirements by intent and does not reproduce copyrighted handbook content.

**Will a good score guarantee I pass my audit?** No tool can promise that. It shows you what a calibrated auditor would probe, so nothing in the core tools surprises you.

**How current is the content?** Question sets track current core-tool editions and IATF Sanctioned Interpretations; subscribers receive quarterly content updates with a changelog.

**Can I assess my suppliers with it?** Yes — run one assessment per supplier and export each CSV. A consolidated multi-supplier dashboard is coming in v2.0 (Enterprise tier).

**We're a Tier 2 with no dedicated quality department. Is this for us?** Especially for you — the 30-minute assessment is designed to replace the 40-hour consultant-prep scramble before a customer audit.

**How do I trend over time?** Re-run quarterly, export CSV each time, and compare — or wait for v2.0 cloud trend charts.

**What if I disagree with a score?** Every question maps to a requirement intent. If your alternate approach achieves the same outcome, document that rationale — that documentation is exactly what you'd show an auditor.
