## Product Features (MVP)

### Core Functionality
- **4-Dimension Risk Scoring:** Certification Status (25%), Process Capability (25%), Audit History (25%), Compliance Gap (25%)
- **Risk Color-Coding:** Green (75-100), Yellow (50-74), Orange (25-49), Red (0-24)
- **SQA Checklist Generator:** 7 standards (AS9100D, ISO 9001, IATF 16949, ISO 13485, FAA Part 21, EASA Part 145, CAAC CCAR-145)
- **CSV Import/Export:** Bulk supplier upload, data backup, ERP integration
- **Offline Operation:** All data stored locally; no internet required
- **Responsive Design:** Desktop, tablet, mobile compatible
- **Demo Data:** 5 pre-loaded suppliers for immediate exploration

### Technical Spec
- Pure HTML/JavaScript (no frameworks, no dependencies)
- Client-side processing (all data stays in browser)
- Local storage persistence (IndexedDB / SessionStorage)
- Cross-browser compatible (Chrome, Firefox, Safari, Edge)
- ~50 KB total size (fast load, minimal network)
