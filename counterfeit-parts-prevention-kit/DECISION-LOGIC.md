# Decision Logic — counterfeit-parts-prevention-kit

## Decision Question
Which counterfeit prevention controls are missing or unevidenced, and what must
be implemented before the next CB/prime/DFARS-relevant audit?

## Inputs
Commodity types, sourcing channels used, current procedures, inspection
capability, escape history, contract flow-downs.

## Rules / Logic
Eight control areas (program planning, risk-based sourcing, procurement
flow-down, verification/detection, control of nonconforming suspect parts,
reporting, training, records) each rated compliant/partial/missing with cited
evidence; sourcing decision tree is deterministic (authorized channel? →
traceability available? → escalating verification requirements).

## M-AI Role
Not applicable in the kit. Decision tree is written rules-first for future
M-AI DIM conversion (suspect-part record completeness checks).

## Confidence / Evidence
Ratings require named records; the checklist forbids "compliant" without a
sampled artifact — same discipline a CB auditor applies.

## Recommendation Output
Gap register with the procedure section and record type that closes each gap.

## Human Decision
QM approves risk acceptances (e.g., broker buys) and program scope; management
approves resources.

## Audit / Traceability
Completed self-assessment + gap register retained as program records.
