# Repair Station Readiness Dashboard

Alert-driven compliance intelligence for FAA Part 145 / EASA Part-145 repair stations. Built 2026-07-04; evolved 2026-07-07.

## Quick Start
Open **`artifact/index-v2-fsa.html`** in any modern browser. That's the production version (FSA-compliant alert-driven UI). `artifact/index.html` is the archived v1 dashboard — reference only.

Pick a demo station, review the alerts (each answers: what / why / what changed / why it matters / what needs attention / next step / consequence of inaction), filter by severity, print the report.

No backend, no login, no internet required. No data leaves the browser.

## Data Sources — Honest Statement
v1.0 uses user-supplied records plus monthly-refreshed public FAA/EASA records with visible currency dates. There is **no live regulator API** in v1.0; automated refresh is v1.1. Do not market live-data claims.
