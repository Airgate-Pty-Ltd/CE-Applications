# Product Roadmap — Repair Station Readiness Dashboard
**Date:** 2026-07-07 | Supersedes the version roadmap in COMPLETION-MARKER.md

## v1.0 — Launch (July 2026) — CURRENT
- Alert-driven intelligence UI (index-v2-fsa.html) with demo data
- User-supplied station data (manual entry / CSV) — honestly labeled
- 3-dimension scoring: Regulatory Status (35%) / QMS Maturity (40%) / Supplier Health (25%)
- Printable readiness report; Gumroad trial link
- **Exit criteria:** deployed demo URL + first 5 trial signups

## v1.1 — Data + Kernel (Aug–Sep 2026)
- M-AI Kernel integration: alerts generated by governed rules (DIMs), not hardcoded data — satisfies AI Architecture Requirement (local, deterministic, no external API)
- Monthly public-data refresh: FAA DRS / repair-station directory import, EASA Part-145 approvals list import, with data-currency stamps in UI
- Supplier Scorecard v2.0 live feed (ecosystem bundle)
- Email digest (weekly posture summary)
- **Exit criteria:** zero hardcoded alerts; data-currency visible on every screen

## v1.2 — Multi-Station / Enterprise (Q4 2026)
- Consolidated holding-company view (N stations, one screen)
- Role-based access (QD vs. Ops vs. executive read-only)
- White-label option for consultants
- Slack/Teams alert routing
- **Exit criteria:** first enterprise pilot (2–3 station group)

## v2.0 — Predictive (Q1 2027)
- Local-LLM narrative briefings (Ollama/Qwen3 first; external API optional per provider abstraction)
- Peer benchmarking (anonymized cross-station percentiles)
- Predictive surveillance-finding risk model (trained on aging patterns, not customer data exfiltration)
- Mobile-responsive PWA

## v3.0 — Platform (H2 2027)
- API for eQMS/ERP connectors; CAAC / UK CAA / TCCA regulator packs (see Compliance-Gap.md)
- Audit-evidence vault (exportable regulator-ready package)
