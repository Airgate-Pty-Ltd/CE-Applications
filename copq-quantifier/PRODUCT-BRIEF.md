# Cost of Poor Quality (COPQ) Quantifier
**Brand:** Conform-Edge Quality Consulting  
**Category:** Software / HTML Calculation Tool  
**Status:** Publish-ready (verified 2026-08-15)

## Problem
Every AS9100 / ISO 9001 management review requires analysis of QMS performance — and COPQ is the most compelling management input because it converts quality problems into money. But most organizations either don't calculate COPQ, do it inconsistently across departments, or use a spreadsheet that doesn't generate insight or a management-ready report.

## Solution
A browser-based COPQ calculator using the PAF (Prevention-Appraisal-Failure) model. Four input tabs cover 35 cost line items. Results include:
- Category breakdown and proportional bar chart
- Industry benchmark comparison
- Intelligent insights (failure-heavy, external escapes, prevention underinvestment)
- Management-review-ready summary table
- Copyable text block for direct paste into management review minutes
- JSON export for MRA integration

Aligned to AS9100D 9.1.3 / ISO 9001 9.1.3 (analysis and evaluation of QMS performance).
