# AS13100A Aero-Engine Supplier Readiness Tool
**Brand:** Conform-Edge Quality Consulting  
**Category:** Software / HTML Self-Assessment Tool  
**Status:** Publish-ready (verified 2026-08-15)

## Problem
AS13100A compliance date was March 31, 2026. Aero-engine supply chain suppliers to GE Aerospace, Rolls-Royce, Pratt & Whitney, Safran, and Honeywell now face active surveillance against this standard. There is no affordable self-assessment tool covering the full AS13100A requirement set with OEM-specific context.

## Solution
A single-file, browser-based deterministic self-assessment tool covering 8 requirement families across 52 elements:
1. QMS Foundation (AS9100D + AS13100A)
2. Key Characteristics & Special Characteristics
3. First Article Inspection (AS9102)
4. Special Processes & Nadcap
5. Non-Conformance & Supplier Corrective Action
6. Traceability & Configuration Management
7. Subtier Supplier Control
8. Personnel Competency & Authorized Release

Each element is answered as Implemented/Partial/Not Implemented/N/A. Results produce per-family verdicts (COMPLIANT / CONDITIONAL / NON-COMPLIANT), a prioritized gap list sorted by severity, OEM-specific context notes, and an overall readiness gate.
